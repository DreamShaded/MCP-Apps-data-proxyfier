## What to build

Кэш-слой для чтений (режим B). Путь чтения: проверить кэш → хит = мгновенный возврат; мисс = вызвать live-источник → записать → вернуть. Хранилище — плоские JSON-файлы в `cache/data/`, ключ = нормализованный «инструмент + аргументы». Поверх — обёртка с **таймаутом (~8с)**: если live не успел, вернуть фолбэк (закэшированный пример или аккуратный фолбэк-маркер для UI), не повиснуть. Золотые фикстуры коммитятся; рантайм-мисс пишется с коротким TTL, золотые — практически бессрочно. Скелет `pnpm seed:cache` (наполнение реализуется в 09). Этот слой не зависит от Playwright — тестируется с фейковым источником.

- [x] Мисс вызывает источник, пишет результат, возвращает его

- [x] Скелет `pnpm seed:cache` существует (точки наполнения — заглушки)
- [x] Юнит-тесты через шов кэша с фейковым источником: хит, мисс, таймаут→фолбэк, истечение TTL
- [x] `cache/data/` содержимое в `.gitignore`, кроме явно коммитимых золотых фикстур

## Implementation notes

Кэш-слой: `packages/server/src/cache/` — `buildCacheKey` (глубокая сортировка
ключей + тримминг/нижний регистр строк → стабильный ключ; sha256 →
`<инструмент>-<хэш16>.json`), `CacheStore`/`JsonFileCacheStore` (золотые
фикстуры в `cache/data/golden/` — коммитятся; рантайм-миссы в `cache/data/` —
в `.gitignore`; битый/отсутствующий файл → `null`), `CachedReader.read(tool,
args, source)` — хит → мгновенно; мисс → источник под таймаутом (8с) → запись;
таймаут/ошибка → фолбэк (протухший пример или маркер `data:null`). Результат
тегирован: `{ source: 'hit'|'miss'|'fallback', data, stale, fetchedAt }` —
инструменты 04+ по `source` решают, рисовать ли фолбэк-UI. TTL рантайм-мисса —
60 мин; золотые (`ttlMs:null`) не истекают. `createCache()` — корень
композиции. `pnpm seed:cache` (`seed-cache.ts`) — скелет; живой прогон золотых
сценариев — срез 09. Слой не зависит от Playwright (источник инъектируется).
Тесты (20): нормализация ключа, стор (round-trip / битый JSON / golden-приоритет),
ридер через шов с фейк-источником (хит / мисс / таймаут→фолбэк / истечение TTL /
битая метка времени / золотая фикстура). Сборка зелёная, 39/39 тестов.
