# 03 — Кэш-слой: JSON-стор, нормализация ключа, таймаут+фолбэк

Type: AFK

## What to build

Кэш-слой для чтений (режим B). Путь чтения: проверить кэш → хит = мгновенный возврат; мисс = вызвать live-источник → записать → вернуть. Хранилище — плоские JSON-файлы в `cache/data/`, ключ = нормализованный «инструмент + аргументы». Поверх — обёртка с **таймаутом (~8с)**: если live не успел, вернуть фолбэк (закэшированный пример или аккуратный фолбэк-маркер для UI), не повиснуть. Золотые фикстуры коммитятся; рантайм-мисс пишется с коротким TTL, золотые — практически бессрочно. Скелет `pnpm seed:cache` (наполнение реализуется в 09). Этот слой не зависит от Playwright — тестируется с фейковым источником.

## Acceptance criteria

- [ ] Нормализация ключа стабильна (одинаковые аргументы → один ключ независимо от порядка/регистра)
- [ ] Хит возвращается без обращения к источнику
- [ ] Мисс вызывает источник, пишет результат, возвращает его
- [ ] Таймаут источника → возврат фолбэка, без зависания
- [ ] TTL различается: золотые фикстуры долго живут, рантайм-мисс — коротко
- [ ] Скелет `pnpm seed:cache` существует (точки наполнения — заглушки)
- [ ] Юнит-тесты через шов кэша с фейковым источником: хит, мисс, таймаут→фолбэк, истечение TTL
- [ ] `cache/data/` содержимое в `.gitignore`, кроме явно коммитимых золотых фикстур
