# 04 — Megamarket: search_products → грид-вью рендерится

Status: ready-for-human

## Parent

## What to build

Первый реальный флоу Megamarket как мини-SPA MCP App. Инструмент `search_products(query, filters)` через кэш-слой (хит → мгновенно; мисс → live Playwright по megamarket.ru) возвращает `structuredContent` со списком товаров. UI рендерит выдачу (фото, название, цена, рейтинг) в песочнице-iframe Claude Desktop. Запросы из золотого набора отдаются из кэша; произвольные — вживую. Инструмент обёрнут таймаутом+фолбэк-UI.

## Дизайн (аутентичность Megamarket + адаптация под чат)

Визуал — **настоящий Megamarket**, не «похоже на маркетплейс». Источник — **живой сайт**: при реализации (Playwright-сессия уже открывает megamarket.ru, срез 02) делаем скриншоты ключевых экранов через `agent-browser`, извлекаем дизайн-токены через `ai-multimodal` (фирменный фиолетовый/градиент, типографика, радиусы, тени, плашки цены/скидки/рейтинга/бейджей).

- Токены выносятся в общий модуль (напр. `packages/ui/src/megamarket/design-tokens.ts`), переиспользуемый деталкой/корзиной (срезы 05–07).
- **Адаптация под чат-iframe, а не копия десктопа 1:1.** Ширина узкая (видимая ширина чата), высота ограничена. Решать по факту: если оригинальные карточки крупные — компактный **список / плитка-лайт** вместо тяжёлого грида; урезанная плотность, сжатые фото, лимит видимых позиций, без горизонтального скролла. Цель — узнаваемый бренд при читаемости в чате.
- Автоподгон высоты — `useAutoResize` из `@modelcontextprotocol/ext-apps/react`.
- Single-file + песочница: **без внешних шрифтов/CDN** — системный стек, имитирующий бренд, либо инлайн-сабсет.
