# 06 — add_to_cart (из грида и деталки) + view_cart

Status: ready-for-agent
Type: HITL

## Parent

PRD: `.scratch/mcp-app-proxyfier/PRD.md`

## What to build

Корзина = **реальный сайт**. `add_to_cart(id)` — это **app-initiated tools/call**, который через Playwright выполняет живой клик «в корзину» на megamarket.ru под залогиненной сессией (повторяет естественный user-flow, мягче для антибота, чем bulk). Кнопка доступна **и из выдачи, и из деталки**; во время клика карточка показывает маленький лоадер (live-write). `view_cart` возвращает состояние реальной корзины (товары, количество, сумма) → вью корзины в том же App. Действия сериализуются мьютексом.

## Дизайн

Использует дизайн-систему Megamarket из среза 04 (`megamarket/design-tokens`), снятую с **живого сайта**; вью корзины и бейдж корзины должны визуально соответствовать настоящей корзине Megamarket (строки позиций, количество, сумма, итого). Адаптация под узкий чат-iframe по факту (список позиций, компактные строки), `useAutoResize`, без внешних шрифтов.

## Acceptance criteria

- [ ] Вью корзины и бейдж визуально соответствуют настоящей корзине Megamarket, адаптированы под чат-iframe

- [ ] `add_to_cart` выполняет реальный клик «в корзину» под сессией (товар появляется в настоящей корзине Megamarket)
- [ ] Кнопка работает из грид-вью и из вью деталки
- [ ] Во время live-добавления показывается индикатор загрузки в карточке
- [ ] `view_cart` возвращает актуальное состояние реальной корзины (позиции, количество, сумма)
- [ ] Вью корзины рендерится в том же App; бейдж корзины обновляется
- [ ] Операции сериализуются (нет параллельных кликов по одной странице)
- [ ] **HITL:** в Claude Desktop добавление из обоих мест и просмотр корзины работают
- [ ] Тест слоёв инструментов `add_to_cart`/`view_cart` через шов с фейковым драйвером
