# 07 — checkout → хэндоф «открыть в браузере»

Status: ready-for-agent
Type: HITL

## Parent

PRD: `.scratch/mcp-app-proxyfier/PRD.md`

## What to build

Завершение флоу Megamarket. `checkout` возвращает данные для хэндофа (ссылка на страницу корзины/оформления Megamarket); UI показывает кнопку **«открыть в браузере»**, которая выводит вперёд живое headed-окно Playwright уже на **заполненной настоящей корзине** (товары там из срезa 06). Дальше пользователь дозавершает оплату руками в том окне. Реальная платёжная страница/3DS намеренно **не** встраивается в чат (frame-busting сайта + закрытая песочница; данные карты не проходят через наш UI).

## Дизайн

Экран хэндофа/«оплатить» использует дизайн-систему Megamarket из среза 04 (`megamarket/design-tokens`), снятую с **живого сайта** (фирменная кнопка-CTA, итоговая сумма как на настоящем оформлении). Адаптация под узкий чат-iframe, `useAutoResize`, без внешних шрифтов.

## Acceptance criteria

- [ ] Экран checkout/«открыть в браузере» визуально соответствует бренду Megamarket, адаптирован под чат-iframe

- [ ] `checkout` возвращает корректные данные хэндофа (ссылка на реальную корзину/оформление)
- [ ] Кнопка «открыть в браузере» выводит вперёд headed-окно на заполненной корзине
- [ ] Корзина в открытом окне содержит товары, добавленные в срезе 06
- [ ] Карта/3DS в чат не встраиваются (по дизайну); поведение задокументировано
- [ ] **HITL:** в Claude Desktop сценарий «оплатить → открыть в браузере → корзина заполнена» проходит целиком
- [ ] Тест слоя инструмента `checkout` через шов
