## What to build

Второй флоу как **отдельный MCP App** (свой `ui://` ресурс, без корзины/оплаты). `search_deposits(amount, term)` через кэш-слой тянет линейку вкладов и **полную сетку ставок** (срок × порог суммы × капитализация) со sberbank.ru. UI рендерит карточки вкладов со **слайдерами суммы/срока**; пересчёт доходности — **целиком на клиенте** из отданной сетки, к серверу при движении слайдера не ходим. Логика пересчёта выносится в чистый тестируемый модуль. Можно разрабатывать параллельно ветке Megamarket после срезов 02/03.

## Дизайн (аутентичность Сбера + адаптация под чат)

Визуал — **настоящий Сбер**, не «зелёный банк вообще». Источник — **живой сайт**: при реализации (Playwright уже открывает sberbank.ru) делаем скриншоты страниц вкладов через `agent-browser`, извлекаем дизайн-токены через `ai-multimodal` (фирменный зелёный Сбера, типографика SB Sans / системный аналог, радиусы, тени, стиль карточек вклада и контролов).

- Токены — в отдельный модуль (напр. `packages/ui/src/deposits/design-tokens.ts`); это **своя** дизайн-система, не общая с Megamarket.
- **Адаптация под чат-iframe.** Узкая ширина, ограниченная высота. По факту: карточки вкладов вертикальным списком, компактные слайдеры суммы/срока, читаемая плашка итоговой доходности без горизонтального скролла.
- Слайдеры — на бренд-токенах Сбера (трек/ползунок), без внешних UI-CDN. `useAutoResize`.
- Single-file + песочница: **без внешних шрифтов/CDN** — системный стек, имитирующий бренд, либо инлайн-сабсет.

## Acceptance criteria

- [ ] UI визуально соответствует настоящим вкладам Сбера (токены сняты с живого сайта), адаптирован под узкий чат-iframe

- [ ] `search_deposits` возвращает линейку вкладов + полную сетку ставок (срок × порог суммы × капитализация)
- [ ] Чтение идёт через кэш-слой; таймаут/сбой → фолбэк-UI
- [ ] Слайдеры суммы и срока пересчитывают доходность мгновенно на клиенте, без вызовов сервера
- [ ] При смене порога суммы/срока применяется корректная ставка из сетки
- [ ] Пересчёт доходности вынесен в чистую функцию, покрыт юнит-тестами (границы порогов, капитализация)
- [ ] **HITL:** в Claude Desktop карточки вкладов и живые слайдеры рендерятся и пересчитывают
- [ ] Тест слоя инструмента `search_deposits` через шов
