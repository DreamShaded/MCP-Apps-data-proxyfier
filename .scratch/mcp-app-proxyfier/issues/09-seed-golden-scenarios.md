## What to build

Наполнение `pnpm seed:cache`: заранее прогнать «золотые» запросы и сохранить ответы в коммитимые фикстуры `cache/data/`, чтобы на демо они отдавались мгновенно. Минимум: «беспроводные наушники до 5000 ₽» (`search_products`) **+ деталки** товаров, попадающих в эту выдачу (`get_product`), и «вклад 500к на год» (`search_deposits`). Скрипт идемпотентен и перезаписывает золотые фикстуры по требованию.

## Acceptance criteria

- [ ] `pnpm seed:cache` наполняет кэш золотыми сценариями вживую через Playwright
- [ ] Закэшированы: search наушников, деталки товаров из этой выдачи, search вкладов
- [ ] Золотые фикстуры коммитятся в `cache/data/` (исключены из общего ignore)
- [ ] На демо золотые запросы отдаются из кэша мгновенно (без обращения к сайту)
- [ ] Скрипт идемпотентен (повторный прогон обновляет фикстуры без дублей)
