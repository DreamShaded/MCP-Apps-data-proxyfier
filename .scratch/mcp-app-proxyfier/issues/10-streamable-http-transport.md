## What to build

Фаза 2 для сценария «владельцы подключают коннектор сами». Добавить **Streamable HTTP** транспорт за тем же интерфейсом транспорта (из среза 01), чтобы инструменты не переписывались. Сервер запускается в режиме HTTP с публичным HTTPS-URL (туннель `cloudflared`/`ngrok` к локали — чтобы сохранить живой headed-браузер на машине докладчика). Документировать добавление как custom connector в claude.ai. Не блокирует демо фазы 1.

## Implementation notes

- Новый провайдер `HttpTransportProvider` (`packages/server/src/transport/http-transport-provider.ts`) за тем же швом `ServerTransportProvider`; `server.ts` и инструменты не тронуты.
- Выбор транспорта: `select-transport-provider.ts` — флаг `--transport http` приоритетнее `MCP_TRANSPORT`; плюс `--host/--port/--path/--token` ↔ `MCP_HTTP_*`.
- Одна сессия на процесс (один докладчик за туннелем); общий браузер сериализован тем же мьютексом. Многопользовательский режим — YAGNI, вне рамок.
- Безопасность: опциональный Bearer-токен (`MCP_HTTP_TOKEN`) — туннель к залогиненному банк-браузеру не должен быть открытой ручкой. Bind только на localhost.
- Остаточный риск: при «грязном» обрыве туннеля сессия не сбрасывается → рестарт процесса. Задокументировано в README.
- Тесты: реальный round-trip SDK-клиента по HTTP (те же тулы/ресурсы) + матрица выбора транспорта + гейт токена. 108 тестов зелёные; HITL-рендер на claude.ai — вручную перед демо.
